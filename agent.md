# Agents.md

## Project Overview

Daylist is a simple To-Do List web application built for the HNG Internship 15 Stage 1 task.

## Technology

- HTML
- CSS
- JavaScript
- Browser Local Storage

## AI Agent Usage

AI coding agents were used during development to assist with:
- Generating and modifying code
- Debugging issues
- Improving the user interface
- Refining application functionality
- Reviewing the implementation

## Project Guidelines

When modifying this project:
1. Preserve existing functionality.
2. Keep the application simple and user-friendly.
3. Do not add unnecessary authentication.
4. Keep the code organized and maintainable.
5. Test changes before considering them complete.

## Application Features

The application supports:
- Creating tasks
- Editing tasks
- Adding notes
- Setting task priorities
- Completing and uncompleting tasks
- Filtering tasks
- Deleting tasks
- Saving tasks using browser Local Storage

## Running the Project

The application does not require a build step or installation.

Open `index.html` in a web browser to run the application.
